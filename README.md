A tiny Node 22 program (stdlib only, no network) that writes one original sentence of horror — a dentist's drawer, a labelled tooth, and a date three years from now — to `$MAKEFUN_OUTPUT_DIR/entry.txt` with no trailing newline, and prints it to stdout. The line is fixed and deterministic, so every run produces the same 124-character entry, and the program guards the gate itself: one sentence, 1–200 characters, never only whitespace. It fits the brief because the scare lands in a single breath from one concrete, specific image, with the last words doing the frightening.

## Run it

```sh
node main.ts
```
